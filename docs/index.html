Partage avec le Mac

Sur ce téléphone, colle un jeton GitHub limité au dépôt poulailler : chaque synchronisation envoie alors les mesures sur la branche « donnees ». Sur le Mac, ouvre la même adresse : sans jeton, la page affiche ces données. Le dépôt est public, ces relevés le sont donc aussi.

Mettre à jour le programme

Choisis le fichier firmware.bin (sur le Mac : .pio/build/esp32c3/firmware.bin, envoyé par AirDrop). Reste près du poulailler, écran allumé, environ 1 min 30. Si l'envoi échoue, la carte garde son programme actuel.

Journal technique

Événements Bluetooth et erreurs brutes, gardés sur ce téléphone. Pour un dépannage : Copier, puis colle-le à Claude.
